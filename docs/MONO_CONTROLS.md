# 黑白字体、功能清理与下拉控制栏

基于已上机验证的 093e9df（2026-09-22）。不改变首页卡片布局、分辨率、分区表、字体分区、屏幕 LUT、USB/上电修复或音频任务栈。产品页面继续是 480×800 的 1-bit framebuffer。

## 字体

工程原有素材已经来自 HarmonyOS Sans SC。之前除时钟外，优先取 26px 的完整字库，再使用最近邻缩放到各个界面字号，导致固定界面文字也被重复缩放。

现在优先使用同一鸿蒙字体在每个 UI 字号原生生成的内嵌字形；未收录的汉字仍由完整字库补齐，缩放采用整数面积覆盖后一次二值化。最终 `Pixel` 只返回黑/白，不输出灰阶，不使用有序抖动。字框和布局参数不改。内嵌素材的 2bpp 仅是已有离线覆盖度数据，不表示屏幕采用灰色 UI。

没有增加或发布 TTF/fontpack 文件，不必刷新 font_data。黑白像素不能消除所有斜线台阶，此修正消除的是额外的缩放采样损失；实际锐度和残影需在屏上确认。

## 下拉控制栏

从顶部 64px 区域向下滑动至少 64px 打开；点击状态栏也可打开。上滑或 HOME/PREV/BACK 收起，恢复原页面和草稿。只在手势结束时切换，不做连续刷屏动画。原闹钟卡片优先级最高；密码明文显示进入控制栏即取消，密码页仍禁止串口导出 framebuffer。

- 音量：减/加与点按横条，范围 0–100，调用原音量接口；设置不在显示锁内执行。
- 网络：进入原 Wi-Fi 扫描、密码和连接流程；编辑未完成时不跳走，提示先完成或取消输入。原 4G/Wi-Fi 选择逻辑不变。
- 蓝牙：调用已有 HAL 的实际 BLE 扫描，可停止并分页查看附近广播设备。扫描结束释放栈；仅允许音频空闲时启动，闹钟到期请求停止扫描。**不是蓝牙耳机配对，也不是外置音频模块电源开关。**官方板级无 BT_POWER 控制，切换 AT 音频模式可能影响 I2S 时钟，故不提供假开关，不发送未经验证的关机/配对指令。
- 铃声/震动：分别控制闹钟与日程提醒，NVS 成功提交后才改变状态；失败保留旧配置。两者关闭仍显示到期卡片。音量 0 仍使铃声静音；这不关闭原有触摸短震。铃声播放失败最多每 5 秒重试，避免反复申请音频栈。

## 功能逐项归类

| 页面/功能 | 此版本行为 | 仍有边界 |
| --- | --- | --- |
| 小智对话、原文/回答分页、停止 | 保留真实语音通信，忙闲状态匹配可用按钮 | 需要小智服务，离线不伪造回答 |
| 整理灵感、待办草稿、翻译英文 | 保留原有真实 QuickAction，未完成时不显示可执行按钮 | 待办只生成草稿，不声称创建提醒 |
| 存为笔记 | 冻结已完成对话为本地编辑草稿，确认保存后用与 MCP 一致的源指纹归档，原文不可改，重试去重 | 原文/整理版各 1536 UTF-8 字节；答案过长时明确告知草稿先放原文，不静默截断；总容量仍 8 条 |
| 最近胶囊 | 触摸及实体键都实际调用恢复，而非仅跳到当前对话 | NVS 只保留最近一条，不是无限历史 |
| 笔记新建、编辑、搜索、保存 | 复用真实 SD Store/Writer，保存失败保留草稿，版本冲突不覆盖 | 删除与提醒关联仍通过现有 MCP 工具 |
| 阅读 | 删除固定三页演示；读取 `/sdcard/books/*.txt`，书库、翻页、单条阅读位置 NVS 恢复 | UTF-8、单本 256 KiB、最多列 32 本；非 EPUB/PDF，不包含 AI 伴读 |
| 卡片详情/留屏 | 移除虚构示例和创建时间，展示选中卡片的冻结快照 | 不声称写入长期历史；留屏不是关闭无线电的深睡 |
| 系统信息 | 显示真实版本、当前网络、显示方式、字体说明 | 不伪造性能或连接状态 |
| 设备设置 | 原诊断/灰阶测试入口替换为控制中心 | 工程串口诊断保留，正常 UI 不进入灰阶模式 |
| 闹钟/日历 | 真实列表、开关、日期浏览、停止/稍后、语音创建仍保留；接入提醒输出偏好 | 不新增手动日期编辑器；语音依赖服务 |
| 录音 | 真实短录音/回放仍保留；取消、文件不可用提示不改 | 最长 30 秒；不把已有 WAV 当成已转写内容 |
| 天气/额度、Wi-Fi | 保留真实请求状态、缓存时间、扫描及密码验证 | 未配置源时明确无数据，不生成演示结果 |

旧 Confirmation 枚举为兼容保留，但无菜单再展示虚构的确认任务；旧 Reader 三页计数路由已移除。

## 拼音键盘

字母模式采用 QWERTY：第三排左侧为大小写切换，右侧为常见退格轮廓图标，底部空格加宽。符号页因第三排完整十个符号，退格保留右下角。点击退格先删除拼音组合，再删除光标前一个完整 Unicode 字符；不按字节截断汉字。未增加未验证的长按连删。按键绘图和命中共用布局定义。

## 验证/上机

主机命令：`python3 tools/check_mono_controls.py`、原 14 组检查及 `python3 tools/render_ui_preview.py`。新测试执行实际 Font/Reader/QuickControls/NoteWriter 代码，硬件、NVS、任务和 BLE 由受控适配器模拟；读书文件使用临时目录。预览用仓库实际位图和绘图/路由，不能替代触摸/无线电/屏幕光学验收。

仍用 ESP-IDF 6.0.1 `idf.py build`，确认设备分区与端口后仅 `app-flash`。不必重刷字体、NVS、分区或 OTA 选择。建议真机检查：首次进入控制栏内存余量；调音量后语音与铃声；静默到期卡片；BLE 扫描和取消之后小智仍有声音；密码页上下拉不泄露明文；两轮小智整理后触摸归档；中文 TXT 重启后恢复位置。
