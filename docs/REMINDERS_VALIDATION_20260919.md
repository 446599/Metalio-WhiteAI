# 闹钟与 MCP 设备验证（2026-09-19）

## 已交付行为

- 小智 WebSocket 暴露六个本地 MCP 工具，提供时间查询与提醒增删改查、停止。
- 独立闹钟页显示时间、日期和标题；只通过明确的停止、稍后按钮或语音停止工具结束。
- HOME、PREV、NEXT、SELECT、空白区、按钮间隙不能关闭闹钟。
- 默认“轻铃”为三个音符的本地 PCM，带渐入、渐出；与 TTS 共用播放任务。
- 录音暂时压住铃声，录音结束且无 TTS 时恢复。录音任务栈在启动时预留，避免
  响铃占用内存后申请 40 KiB 连续栈失败；预留任务空闲时不开麦、不创建编码器。
- 稍后提醒持久保存 5 分钟延后时间，不改变重复闹钟第二天的原定时间。
- 连续响铃三分钟后静音，页面仍保留等待明确处理。

[设备帧缓冲截图](ui/qa/alarm-device-20260919.png)来自设备 FRAME? 回复，CRC 校验通过；
它用于确认固件画面，并非相机拍摄的墨水屏光学效果。用户试听后确认铃声音量、音色合适。

最后一次音频检查：send_err=0、enc_err=0、dec_err=0、in_fail=0；
录音栈剩余 16768 字节，播放栈剩余 22688 字节，提醒任务栈剩余 5852 字节。

不将其记为实体 TTS 与铃声同时运行的实测证据。
