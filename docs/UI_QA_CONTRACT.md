## 锁屏、按键与低功耗（本次新增）

锁屏不透明覆盖整个framebuffer，后台状态、AI更新和直接产品重绘均不能覆盖壁纸。自定义P4 PBM为480×800、48000数据字节，黑=1需转为framebuffer黑=0；底部y>=664用于锁屏说明。不合法/无文件回退默认文字页，无每秒重绘或时钟动画。

POWER短按锁屏/唤醒，长按仍原关机流程。唤醒按下/松手/Click去重，电源键仍按下时不立即再睡。普通触摸/盖板/AI键不可穿透锁屏，串口仅保留只读诊断和显式WAKE/SLEEP。密码明文状态清除，未提交草稿保留。

自动锁屏默认300秒，有未提交表单不自动锁；对话、音频、网络配置和写入忙时不强制休眠。准备期间排空存储、暂停网络，超时或外设失败恢复原页面。真实CPU浅睡须通过活动屏障，先停Wi-Fi、I2S和按键定时器；USB数据主机、4G与实验BLE场景只锁屏，不进入CPU浅睡。

定时维护唤醒不重绘壁纸、不重连网络；下一提醒前预唤醒，到期提醒恢复UI。暂停/恢复失败不能误报成功，DMA未恢复不强开功放。SLEEP的ACK只代表排队，SLEEP?计数才表示经过睡眠调用；截图不等于实际续航或唤醒已验收。

## 主机、构建与实机边界

运行原产品回归以及check_sleep_contract.py、check_transport_health.py、render_ui_preview.py。使用仓库实际字体和绘图/命中；硬件/无线电/RTOS按测试用途模拟。覆盖正常、离线、空内容、长文本和过期数据，检查缺字/文字越界、密码保护、壁纸保持、按键唤醒去重、屏障竞争和失败回滚。
