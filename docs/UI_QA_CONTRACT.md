# UI 与串口主机侧 QA 契约

这份契约对应 `main/display/raw_display.cc` 的固定几何常量，不改变固件行为。

## 坐标与命中区

- 逻辑 UI 固定为 **480×800 竖屏**；SSD1677 物理 RAM 为 800×480 横屏。
- 首页命中区采用左闭右开坐标：AI 主卡 `x=32..447,y=260..379`；天气
  `x=32..447,y=158..243`；额度 `x=32..447,y=590..683`。
- 首页底部自定义信息带 `x=32..447,y=700..777` 是展示区，不触发刷新或聆听。
- 产品页底栏（启用产品页路由时）为 16 px 边距的 2×2 按钮：
  `x=16..231/248..463`，`y=640..703/720..783`。
- 旧版测试控制台六个按钮保持 `x=28..451`、高 92 px，顶部 y 为
  `132,236,340,444,548,652`。

运行源码级几何检查：

```bash
python3 tools/check_ui_contract.py
```

主机注入触摸必须使用 480×800 坐标；`gesture` 子命令在同一串口会话中发送
DOWN/MOVE/UP，避免 USB Serial/JTAG 重开导致目标复位。

## 帧 dump 证据边界

`python3 tools/miaoink4_serial.py frame` 校验 CRC、长度、步长并可写出 PBM，
这些结果只证明设备传回了一份自洽的逻辑 framebuffer；`frame --panel` 只改变
为面板旋转坐标的导出。串口初始化日志和 `Hash of data verified` 同样不能证明
肉眼看到的像素、残影质量、实体触摸响应或网络业务成功。

没有实机观察/触摸记录时，报告应明确写成：**主机协议与源码契约通过，光学/实体
交互未验证**。
