# UI 与串口主机侧 QA 契约

坐标对应 `main/display/raw_display.cc`。产品页和旧版诊断界面分别维护几何，
首页使用 Nothing 风格的黑白排版、静态点阵时钟和 32 px 安全边距。

## 当前产品页

逻辑 UI 为 **480×800 竖屏**；SSD1677 物理 RAM 为 800×480 横屏。
所有命中区为左闭右开，下表的右边界和下边界不响应点击。

| 区域 | x | y | 操作 |
|---|---|---|---|
| 首页闹钟 / 日历 | 32..232 / 248..448 | 296..440 | 独立闹钟列表 / 月历 |
| 首页录音 / 小智 | 32..232 / 248..448 | 464..608 | 离线录音 / AI 对话 |
| 应用目录 / 设备选项 | 32..232 / 248..448 | 664..728 | 两个平级目录 |
| 大时钟与日期 | 展示区域 | — | 不响应点击 |
| 底部通知 | 32..448 | 752..786 | 被动提示；首页平时隐藏 |

- 首页只保留时钟、日期、四个常用入口和两个目录。天气、额度及其更新状态移到设备状态页。
- 应用列表从 y=144 开始，间距 80 px、命中高 72 px，共六行：闹钟、日历、录音、小智、我的胶囊、阅读。
- 设备选项独立于应用：设备状态、刷新数据、系统信息、屏幕测试。状态和系统信息是只读页，不显示假开关。
- 闹钟每页四项，y=144+112*n。只有 `(344,160+112*n,104,48)` 开关修改该条目；标题与留白不会开关闹钟。
  `(32,600,416,48)` 进入语音添加；多页时 `(32/248,672,200,48)` 上下页。
  按显示时保存的 ID 操作，避免后台排序变化切换错条目。重复闹钟重新启用时自动计算下一次时间。
- 月历 `(32/384,136,64,48)` 翻月；日期网格 x=44..436、y=232..496，每格 56×44。
  点击有效日期显示当天日程，前后空格不响应。每日两项一组，更多按钮在 `(248,688,200,48)`。
  `(32,688,200,48)` 进入语音添加。单次已完成日程仍可在原日期查看；重复事项按星期显示。
- 录音 `(32,496,416,64)` 开始/停止，已有录音且空闲时 `(32,584,416,64)` 回放。
  `(32,672,416,64)` 新建语音文字笔记，进入小智的原文视图，按住 AI 键说话、松开转写并自动保存胶囊。
  两种模式为独立入口；当前不把已有 WAV 文件上传转写。
- 本地录音最长 30 秒。SD 挂载时保存到 `/sdcard/recordings/latest.wav`，替换保留 `.bak` 恢复副本；
  进入录音页恢复最近文件，无 SD 或保存失败时明确显示仅本次开机保留。返回页面、来闹钟时停止音频任务。
- AI 页顶部停止区 `(344,72,104,48)`，原文/回答切换区 `(32,288,184,48)`。下面整理、待办、翻译、保存四按钮保持原有操作。
- 我的胶囊 `(32,504,416,64)` 恢复最近保存的原文与回答。文字按真实字宽裁切或换行。
- 通常只绘制一次目标页面；静止时钟不显示秒，录音中不逐秒刷新墨水屏。普通按键仍不能关闭正在响铃的闹钟。

盖板电容键：HOME `(80,900)` 回首页，NEXT `(240,900)` 下一项/下一页，PREV `(400,900)` 返回/上一页。
日历页 NEXT/PREV 翻月，用 HOME 回首页。首页 NEXT 遍历四格和两个目录，SELECT 打开选中入口。
音量操作仍在主事件任务执行，触摸输入仍用 8 项有界队列。

## 主机检查与真实绘制预览

```bash
python3 tools/check_ui_contract.py
python3 tools/check_reminders_contract.py
python3 tools/check_recorder.py
python3 tools/render_ui_preview.py
```

预览提取真实 C++ 绘制函数，链接真实字体、日程计算和 DashboardData；仅替换硬件、存储服务快照与时钟。
覆盖正常、离线、空、长文本、过期数据五种场景，包括闹钟分页、月历翻月、闰年二月、录音各状态。
每个绘制帧检查缺字与文字越界。`build/ui-preview/<scenario>/` 输出 PBM、PNG、overview.png。
这些是软件预览，不是屏幕照片。录音文件检查覆盖 30 秒往返、错误采样率/声道、超限和截断文件。

## 保留的诊断界面

旧版 dashboard 几何仍为：天气 `x=32..448,y=158..244`，AI 主卡
`x=32..448,y=260..380`，额度 `x=32..448,y=590..684`，自定义信息带
`x=32..448,y=700..778`。它不代表当前启动首页的点击坐标。
旧版测试控制台六个按钮保持 `x=28..452`、高 92 px，顶部 y 为
`132,236,340,444,548,652`。

主机注入内容触摸使用 480×800 坐标；盖板虚拟键在 y=900，不属于 framebuffer。
`gesture` 子命令在同一串口会话中发送 DOWN/MOVE/UP，避免重开串口导致复位。

## 证据边界

`python3 tools/miaoink4_serial.py frame` 校验 CRC、长度、步长并可写出 PBM；
`frame --panel` 只改变导出的旋转坐标。主机预览、串口 dump、编译通过以及
`Hash of data verified` 都不能证明屏幕肉眼效果、残影质量或实体触摸响应。
未进行实机观察时，应明确报告：**主机渲染与源码契约通过，光学/实体交互未验证**。
