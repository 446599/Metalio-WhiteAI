# UI 整合验证 · 2026-09-19

## 交付内容

主页改为时钟、日期与四格入口（闹钟、日历、录音、小智），下方分开应用目录和设备选项。
应用目录只包含日常应用；天气、额度、系统信息、刷新与屏幕诊断移入设备选项。

闹钟页读取 NVS 提醒，按下一次触发排序、每页四项，支持明确的开关与语音添加入口。
日历按月展示，支持翻月、选日期、日程标记和当日列表分页。已完成的单次日程保留在原日期。
原有响铃页的停止/稍后按钮与防误取消行为保持不变。

录音使用现有音频任务与麦克风/扬声器，最长 30 秒，不依赖网络；保留最近一段。
SD 挂载时写入 `/sdcard/recordings/latest.wav`，使用临时文件与 `.bak` 恢复副本；
没有成功存档时，界面明确提示仅本次开机保留。
新建语音文字笔记进入小智原文视图，按住 AI 键录音、松开识别，自动保存到最近胶囊。
本地录音和文字笔记为独立流程，本轮未实现已有 WAV 上传转写。

SHA-256：`8eb9025f2ab17b5789393c93546a191a8cd151b297aeffb9168712f19be380aa`。

串口注入真实触摸/按键并检查页面状态：

- 首页六个入口，应用目录六项，设备目录及返回路径通过。
