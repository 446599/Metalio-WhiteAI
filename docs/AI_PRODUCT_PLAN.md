# AI 墨水屏首页与小智移植计划

## 产品目标
面向 Metalio E-Ink 4（800×480 横屏面板，ESP32-S3）提供低刷新、可读性优先的 AI 桌面：每日日程、天气、AI 重要事项、自定义卡片，以及 Codex 用量摘要。所有数据都允许离线显示最近一次快照。

## 首页信息架构
- 顶栏：日期、时间、电量、网络状态
- 主卡：AI 今日摘要（小智生成，最多 3 条）
- 日程卡：今日待办/日历事件，按时间排序
- 天气卡：当前位置、温度、体感、未来 3 小时趋势
- 自定义卡：用户可配置标题、图标、数值和点击动作
- 用量卡：Codex 5 小时窗口、周窗口的剩余额度；无数据时显示“未连接”

## 小智接入边界
1. `xiaozhi/` 作为独立组件，提供 `XiaozhiClient`、连接状态和事件回调。
2. 音频采集/播放复用现有 `AudioCodec`，网络传输优先 Wi-Fi，4G 作为后续适配。
3. AI 文本只进入本地事件总线；首页订阅摘要事件，避免网络线程直接操作 LVGL。
4. 凭据只存 NVS，日志禁止输出 token、cookie、二维码内容和用户文本。
5. 断网时首页使用本地快照，小智连接状态明确显示为离线/重连中。

## 实施阶段
- Phase 1：首页信息面板和本地数据模型（当前）
- Phase 2：天气、日程、Codex 用量适配器
- Phase 3：小智 WebSocket/音频会话组件
- Phase 4：触摸交互、卡片配置和局部刷新优化
