# 本地拼音输入、Wi-Fi 设置与笔记编辑

基于已上机验证的 dab59281aad363874467d12a28b59a10a5aa4cab；保留 USB mux、上电时序、早期诊断、分区和刷新波形。

## 使用

首页 → 设备设置 → Wi-Fi。自动扫描附近 2.4 GHz 网络，点击网络、点击密码输入区、完成、连接。
列表按信号排序，按名称和安全类别去重，最多24项、每页5项。扫描失败可重试；隐藏网络用手动添加。
仅支持开放网络及 WPA/WPA2/WPA3 Personal；WEP、企业网络等显示不支持。路由器的认证兼容性仍需实机验收。
“已连接”指目标 SSID 获取 IP，不保证互联网、强制门户认证或 AI 服务可访问。失败不冒称是密码错误：可能是信号、认证或 DHCP。
4G 模式必须二次确认切换并重启，不会悄悄更改网络模式。

键盘支持中文拼音、英文大小写、数字和全部可打印 ASCII 符号、空格、退格、左右光标。
中文离线查询固定 GB2312 字库范围的拼音表（字典为文字数据，不包含字体），辅以少量常用词组。
输入完整拼音后点击候选，右侧翻页；v 表示 ü，单引号作音节分隔。不是整句预测/云端输入法，没有词频学习。
密码专用英文键盘，默认遮罩，可显式显示；不发送给模型，不写日志，退出/提交清理编辑缓冲。
硬件及编译器可能保留临时副本，不能把缓冲清理当作加密或物理取证防护。

应用目录 → AI 笔记 → 新建/搜索。标题、项目、正文都能触摸输入；编辑已有归档只改整理版，原文保留。
按字节限制，不截断 UTF-8 字符；完成前需先选择或删除未完成拼音。HOME 离开脏草稿需要确认。
保存通过独立任务执行，提交成功才进入详情；失败留在编辑页保留草稿。仍需 SD，仍最多8条。
搜索支持本地关键词，清空搜索可恢复全部笔记。语音记录入口仍使用 AI 实体键。

## 实现和数据

`main/input`：有界编辑器、离线词表、统一键盘绘制/命中布局。
`main/network`：不含密码的状态快照、扫描与连接工作任务、取消代次、提交阶段。
`components/esp-wifi-connect`：暂存候选网络配置，目标 SSID 获取 IP 后才提交密码；失败/取消恢复保存网络自动连接。
密码未保存前不会调用 AddAuth。开始保存后取消不可接受，界面显示正在保存，避免提交与取消竞争。
凭据用单个 `wifi/profiles_v2` NVS blob 保存，内存列表只有 commit 成功后更新。兼容读取旧 ssid/password 等键，
首次成功写入才迁移，不删除旧键。新固件优先使用 v2；**旧固件降级仅看到旧键，新的网络设置不会同步给旧版本**。
NVS 未启用加密时凭据仍是明文，和原设计一样；不声称加密存储。损坏 v2 拒绝覆盖，应先备份诊断，不静默清空。

## 字典来源

源：mozillazg/pinyin-data，固定提交 923b108dc5d45dee061324c011b478fb649f8b73，MIT，许可证见 main/input/PINYIN_LICENSE。
`tools/build_pinyin_dictionary.py <pinyin.txt> --out main/input/pinyin_dictionary.inc` 可离线重现。
文件头记录源 SHA-256；固件只需生成的静态数组，不使用 LVGL 或运行时 Python。基础候选按常用字优先、随后 GB2312 顺序。

## 检查

运行 `tools/check_input_network.py`、`tools/check_ssid_store.py` 与所有已有契约；完整 UI 预览同时跑真实新增页面路由。
完整 `idf.py build` 与主机通过也不能代替扫描/错密码/断网/取消/重启自动连接、实际触摸和墨水屏键入速度验收。
